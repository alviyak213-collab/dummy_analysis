Skill-Gap Calculation Formula

4. Trainer Delivery Strategy

Suggested 11-Hour Modular Training Roadmap

Session 1: Cybersecurity Fundamentals

Duration: 2 Hours
  • Confidentiality, Integrity, and Availability (CIA Triad)
  • Threat Landscape: Phishing, Malware, Ransomware, Social Engineering
  • Password Security Policies & Multi-Factor Authentication (MFA)
  • Incident Reporting Channels & Initial Escalation Protocols

Session 2: Python & Linux Hands-on Utilities

Duration: 3 Hours
  • Python File I/O, regex parsing for log investigation
  • Linux CLI: Process monitoring (`top`, `ps`), file permissions (`chmod`, `chown`)
  • System log inspection (`/var/log/auth.log`) & listening sockets (`ss -tuln`)

Session 3-5: Advanced Web Security & Incident Handling

Duration: 6 Hours
  • Network protocols, port scanning detection, firewall rules
  • Web Application vulnerabilities (XSS, SQLi, CSRF, SSRF)
  • Live forensic triage, volatility capture, chain of custody compliance

6. Trainee Action Evaluation Matrix

Standardized Checklist for Assessor Evaluation

Evaluation Phase Trainee Required Action Key Performance Indicators (KPIs)
1. Threat Identification Pinpoint exact threat type (Phishing, Insider Risk, Ransomware) Accurately names the vector without misclassification
2. Impact Analysis Assess potential operational damage to system and data CIA triad Identifies affected data sensitivity, scope, and service impact
3. Immediate Action Perform immediate containment steps (Network isolation, disconnect host) Executes isolation rapidly without powering down volatile RAM state
4. Notification Protocol Escalate incident via official CERT / Cyber Cell channels Logs accurate incident details and routes report to correct authority
